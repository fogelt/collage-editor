# Cursor assets

`grab.png` and `grabbing.png` are the `hand_thin_open` and `hand_thin_closed`
cursors from [Kenney's cursor pack](https://kenney.nl/assets/cursor-pack),
licensed under CC0 1.0.

The app draws these PNGs directly on the collage canvas. `grab.cur` and
`grabbing.cur` are 32x32 native fallbacks generated by
`tools/make_cursors.py`.
